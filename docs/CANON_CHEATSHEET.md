Версия для нового проекта (перенесена из старого без изменения содержания). Собрана по частям А, Б, С. Это сверка, а не новый материал. Новых фактов нет. Часть правил проверяет автоматически `python tools/check.py` (правила в `tools/canon_rules.json`).
Не прочитано: сцены глав 2-9 в части С (строки 124-585).

## 3. Игровые правила [у]

- Плоды: счётчик 0-3, пять дверей (гл. 4, 5, 7, 8, 9), не больше одного плода на дверь; считаются только фактически раскуренные. Не считаются: трубка гл. 1, финик с булавки у Имаада, поднятие, хранение, продажа, отказ, чужое курение. Третий отказ закрывает ветку "ровно три". Третий плод не блокирует другие концовки.
- Голос Улитки: слышат только курившие; не больше 3 появлений (первое курение, гл. 7, Жеби; совпавшие объединяются); "игрок" звучит ровно один раз, при первом появлении; без инструкций и объяснений; Имаад не слышит; только подтверждённая строфа И1.
- Летописец: безымянный писец, живёт позже событий, события не видел, любит красивый конец. Обращается к читателю и потомку, никогда к "игроку". Не читает книгу. В каждой концовке три перечня и полная финальная строка (в конц. 1 без оговорки, в 2-5 с краткой).
- Три слоя: байка (Жак), слух (другие), запись (Летописец). Запись истину не подтверждает. Игрок меняет одну деталь за передачу.
- Главы 6 и 7: одна встреча с двух точек зрения.
- Исход 8.4 по приоритету: продал провиант, затем поддержал Студента, затем (предупредил И был обмен сведениями), иначе нейтральный.
- Слова Жака о судьбе и "ведаю, знаю я всё и везде" - его трактовка и заявление. Не закон мира; "оказывается повсюду" не писать.
- Книга из пяти страниц [у]: в источниках её нет, не объясняет лор, Летописцу недоступна, страницы доступны без курения.
- Дамаск: самостоятельной концовки нет, выбор пути сохраняется.

## 4. Ловушки формулировок

- "хоровод без суда", не "хор без суда".
- Написания в игре: **«Жебь»** (именительный), **«в Жеби»** (предложный; из Жеби, к Жеби, за Жебью), моджахеды, Абдулла, Имаад, Жак (эпитет аль-Бобо), эль-CrewGTW, Джихад. В цитатах форма источника («на базаре в Жеби», «достиг вновь Жеби», «из дальней Жебе» — не править). Норма — распоряжение руководителя 2026-11-08 (П-23 «ожидает [у]»).
- "Абдуллова книга" (название концовки 3) и запретная книга не одно и то же.
- Вторая фраза Улитки "восстань и иди жечь сердца" в источниках отсутствует, цитатой её не считать.
- Студент, Летописец, кассета, счётчик плодов, "уши", концовки - [у]-расширения, не [к].
- Жак в строю в 640 / ушёл из войска в 629: оба факта сохраняются.
