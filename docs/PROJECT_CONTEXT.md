# PROJECT_CONTEXT - SIRIYA (новая версия, с нуля)

Короткий ввод для любого агента. Правила работы: `AGENTS.md`. Канон: три свода в `docs/`. Старый проект не используется; от него остались только своды, исходные тексты и идеи.

## 1. Что за игра

Авторская 2D-игра на Godot 4.7.2 (GDScript), пиксель-арт, базовое разрешение 480x270, целочисленное масштабирование, фильтр Nearest. Вселенная: абсурдная сатира про усатого торговца Жака аль-Бобо, Дамаск, базар Абдуллы, оазисы, моджахедов, ослика Имаада, запретную книгу, плоды (финики тьмы), голос Улитки и Летописца, который записывает версии событий. Главы 0-9, пять концовок, финал в Жеби.

**Геймплей на текущем этапе (решение руководителя):** игрок ходит по миру, встречает персонажей и ведёт с ними диалоги; их рассказы влияют на развитие сюжета (флаги состояния). Сюжет и цельность повествования важнее механик.

**Не проектируется и не добавляется без [у]:** крафт, инвентарь, биомы, бой, копание, постройка блоков. В своде части Б сказано «sandbox-adventure в духе Terraria», но механики песочницы там не утверждены. Платформинг: вне первого среза [с], решается позже.

## 2. Что делаем первым (вертикальный срез)

Две локации и один диалог со сменой состояния:
- **Базар Абдуллы** (глава 2): день, открытая площадь, диалог с Абдуллой.
- **Оазис Жака** (глава 4): вечер, ключ с ситро, пальмы, первая дверь (финик).
Фоны готовы: `assets/backgrounds/bazaar.png`, `oasis.png` (480x270). Герой и NPC пока заглушки.

## 4. Технические принципы

- Данные отдельно от кода (JSON). Состояние сюжета: один autoload `GameState` с флагами из словаря состояний части С, раздел 0.3; сохранение и загрузка в JSON.
- Signal-up/call-down, именованные константы, API Godot 4.7 не угадывать (документация).
- Арт: фоны генерирует руководитель в ChatGPT и Gemini, `tools/art/import_bg.py` приводит к 480x270 и общей палитре с закреплёнными акцентами. Новую картинку: `python tools/art/import_bg.py convert art/src/NAME.png assets/backgrounds/NAME.png --palette art/palette.png --preview`.
- Свет: PointLight2D у фонарей, CanvasModulate по времени суток. 60 FPS на i5-11400 / 8 ГБ.
- Лицензии: только свои, CC0 или OFL, записывать в `LICENSES.md`.
