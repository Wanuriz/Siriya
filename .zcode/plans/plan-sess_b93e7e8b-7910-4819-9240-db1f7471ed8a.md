# ПЛАН АУДИТА ZCODE 3.18.1 И ПРИЛЕГАЮЩЕЙ СРЕДЫ (SIRIYA-инфраструктура) — v3

Периметр: только ZCode и прилегающая инфраструктура. Содержимое игры SIRIYA (исходники, сцены, ресурсы, игровые docs) не читать/анализировать/изменять — включая задания субагентам; целостность репо — только метаданные (git status, HEAD, SHA-256).

Классы: R — чтение без изменения состояния (разрешены сразу после одобрения плана). A — действия внутри ZCode, меняющие состояние приложения (тестовые сессии, запуск субагентов, MCP с подпроцессами) — согласование пакета. W — любая запись/создание данных (TEMP, worktree, документы плагинов) — пооперационное согласование (пути, эффекты). Одобрение плана = только R; A/W без согласования не начинаются.

Статусы: VERIFIED/PARTIAL/BROKEN/UNVERIFIED/NA. Конфиг ≠ работоспособность. Приоритеты P0-P3 — по воздействию в T10.1, не заранее (кроме задач целостности).
